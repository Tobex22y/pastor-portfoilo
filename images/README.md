# Website Images Directory

This directory stores the visual assets for the Beloved Opeyemi Abimbola personal website:

1. **`portrait.svg` / `portrait.jpg`**:
   - Used in the Hero section, replacing the former "OA" placeholder box.
   - Designed with an arched golden frame and metallic badge.
   - **How to use your own photo**: Save your studio photo as `portrait.jpg` (or `portrait.png`) into this `images/` directory. The website's `<picture>` tag is already pre-configured to automatically load `portrait.jpg` whenever it is present!

2. **`book-cover.svg` / `book-cover.jpg`**:
   - Used for the *"More Than Gold"* book showcase.
   - Serves both as the atmospheric blurred background backdrop and as the 3D book cover display.
   - **How to use your official book artwork**: Save your high-resolution book cover image as `book-cover.jpg` (or `book-cover.png`) into this `images/` directory. It will immediately display as both the 3D book cover and ambient backdrop!
